# 强化符文名字识别模型

`app/augment_ocr.py` 用来识别海克斯大乱斗三选一卡片标题的逐字分类器。

**来源**：[RankPeek](https://github.com/wxl11071123/rankpeek)（AGPL-3.0）的 `rankpeek-frontend/public/hextech-model/`，
提交 a09c2de（v1.3.0，2026-10-23），文件原样复制，未修改。识别流程（闸门、切字、约束解码、模糊对齐、
各个门槛）移植自同一项目的 `src/main/hextech/pipeline.ts`、`model.ts`、`fuzzyDecode.ts`。

| 文件 | 内容 |
| --- | --- |
| `W1.f32` / `b1.f32` | 第一层：24×24 输入 → 192，float32 小端，行优先（576×192） |
| `W2.f32` / `b2.f32` | 第二层：192 → 599 个字（192×599） |
| `chars.json` | 599 个字，顺序即输出下标 |
| `names.json` | 随包的强化名字表（237 个），识别时和同步来的官方名单合并 |

模型认的是**字**，不是强化：新强化只要用的都是字表里有的字，加进名字表就能认，不用重训。
名字里有字表外的字（例如"王中王，靴中靴"的"靴"）时，那个强化认不出来，会留空让你手动补，不会认成别的。
